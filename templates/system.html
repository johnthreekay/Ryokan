Provider fallback

Force specific metadata providers for testing the fallback chain.

Debug option for testing the fallback path after AniList comes back. AniList-only entries without a MAL ID cannot be forced into fallback mode.
Debug option for testing Kitsu episode metadata even when Jikan returns titles. This only affects series episode metadata on the detail page.

Grab behavior

Control when and how Ryokan auto-grabs releases.

When enabled (default), Ryokan automatically searches for and grabs all monitored episodes after you add a series to the library. Disable to add series without triggering an immediate download.
When disabled (default), auto-search and RSS use Nyaa's English-translated category. Enable to search all anime categories instead. Interactive search always searches all categories.

Maintenance actions

One-shot operations against the library and metadata cache. Each runs immediately — independent of the Save button below.

Re-fetch AniList (and MAL/Kitsu fallback) metadata for every tracked series. Use when you've noticed stale titles, wrong episode counts, or missing relations after a provider outage or schema change.
Look at every series that was added under a MAL or Kitsu fallback ID and try to upgrade it to its AniList entry. Safe to click repeatedly; only upgrades entries that now resolve on AniList.
Walk every tracked series folder and run the source/resolution classifier on files that don't yet have a structured tag. Useful after migrating from another PVR or dropping files in manually.

RSS grab history

Clear the RSS grab history so previously grabbed episodes can be re-evaluated on the next sync. Use this if you deleted a file from disk and want Ryokan to re-grab it.

Search Tips

Use the uploader field to filter by a specific release group's Nyaa account. The category filter lets you narrow to English-translated or raw releases. "Trusted only" shows releases from verified Nyaa uploaders.

Try searching for batch releases by including "batch" in your query, e.g. "Jujutsu Kaisen batch 1080p".

Grabbing Releases

Click the Grab button next to any result to send it to qBittorrent. The torrent will be added with your configured category. Make sure qBittorrent is running and the connection is configured in Settings.
