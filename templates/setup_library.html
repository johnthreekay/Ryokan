Set up your library

Ryokan renames finished downloads and places them in your media library, the folder Jellyfin reads. If you don't have a media library yet, skip this step and set it up later in Settings → General.

Media library

Each series gets a folder in here. In Docker this is a path inside the container, on a mounted volume.
A hardlink needs the downloads and the library on one filesystem and, in Docker, one mount: mount a single folder that holds both (such as /data) rather than one for each. Ryokan falls back to copy when a hardlink fails.

Jellyfin optional

With Jellyfin connected, Ryokan refreshes its library after each import. Leave both fields empty if you don't use Jellyfin.

Create one in Jellyfin under Dashboard → API Keys.
