Media Library
Root directory where anime series folders are stored. Inside Docker, this must be a mounted volume.
RSS
Poll the official Nyaa anime RSS feed on the interval below and auto-grab matching releases.
Used by the background RSS poller. Manual sync is available on the System page.
Post-Processing
When enabled, Ryokan will rename and move completed downloads into your media library and write NFO sidecar files for Jellyfin. No external metadata providers are queried; data already in the database is used. Requires a configured media root and qBittorrent.
Hardlink is instant and uses no extra disk space, but only works when qBittorrent and the media root are on the same filesystem. Copy is used automatically as a fallback if hardlinking fails.
