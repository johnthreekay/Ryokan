Media Library
Root directory where anime series folders are stored. Inside Docker, this must be a mounted volume.
RSS
Poll the official Nyaa anime RSS feed on the interval below and auto-grab matching releases.
Used by the background RSS poller. Manual sync is available on the System page.
When checked, the background RSS poller skips Nyaa entirely. Indexer-RSS feeds (torznab/newznab) and direct RSS feeds you've configured still run on the same interval. Use this if you only want releases from your configured indexers, not from Nyaa's public feed.
Post-Processing
When enabled, Ryokan will rename and move completed downloads into your media library and write NFO sidecar files for Jellyfin. No external metadata providers are queried; data already in the database is used. Requires a configured media root and a download client.
Hardlink is instant and uses no extra disk space, but only works when the download client and the media root are on the same filesystem. Copy is used automatically as a fallback if hardlinking fails.

Backups
Writes a backup of the database and encryption key on that cadence. Download one at any time from System → Backup, which is also where restores happen.
Empty keeps backups in a backups folder next to the database. The value is the path inside Ryokan's container. A folder on another disk or a mounted share is the point of a backup.
Older scheduled backups are deleted after each new one. Backups taken automatically before a restore are never deleted by this.
Artwork is downloaded again from the metadata providers when missing, so this only saves time after a restore at the cost of a much larger file.
Recycle Bin
Leave empty to disable. When set, deleting an episode or a series folder (and replacing a file during an upgrade) moves it here instead of deleting it permanently, and you can restore it from the Recycle Bin page. Put it on the same filesystem as the media root so moves are instant and keep seeding hardlinks intact. The value is the path inside Ryokan's container. Clearing the path leaves anything already recycled where it is; empty the bin first if you want it gone.
Recycled items older than this are deleted permanently by the hourly cleanup task. 0 keeps everything until you empty the bin yourself.
Monitoring
When you change a series's monitoring mode (e.g. none → all), Ryokan will run a background auto-search for the newly-monitored aired episodes. Off by default; turn on if you want monitoring changes to immediately start grabbing. Narrowing transitions (all → missing, any → none) are a no-op.
Manual search
When you grab a release from the manual search page, Ryokan resolves the release title via anitomy and AniList to find the matching series. If it isn't already in your library, the series is added automatically and the grab is linked to it. Off keeps the legacy behavior: the grab succeeds in the download client but no library row is created.
Downloads
Ryokan checks every grab against the file list the download client reports. When the files clearly name a different series, it removes the download from the client, blocklists the release, sends a notification, and searches again. On by default. Off keeps the download in the client, never imports it, and only flags it under System, Misgrabs, where you can restore or dismiss it.
Display
Used on library cards, detail pages, and AniList search results.
