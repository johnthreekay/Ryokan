# Welcome

**Ryokan** is a self-hosted anime PVR inspired by Sonarr.

It's made around how anime is released: fansub groups, batch packs, [SeaDex](https://releases.moe) picks, AniList for metadata, and auto search that just works.

!!! info "Project status"
    Ryokan is a one-person vibecoded project, so expect some rough edges.

## Get started

Ryokan runs as a Docker container. These docs assume you know what containers, images and volumes are.

!!! tip "Start with the Quick start"
    The **[Quick start](quick-start.md)** lets you build a `docker-compose.yml` for Ryokan, your download client, a media server, and optionally Seerr and a reverse proxy. It then walks you through setting each one up.
