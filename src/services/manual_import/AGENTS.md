# services/manual_import/AGENTS.md

Manual import for existing libraries (#122): the `/system/import` wizard's filesystem and AniList work. The handlers are `handlers::system::manual_import` (`src/handlers/AGENTS.md`).

Keep this file under 40,000 characters (`wc -m`): past that, a Claude Code session with a 200K context window is given only its start. `tests/agents_md_audit.rs` enforces it.

## Layout

- `manual_import/` — #122 manual import for existing libraries. `walk.rs` (walkdir over a user folder: hidden / junk-dir / symlink toggles, Ryokan's `media_root` + recycle bin always excluded, 50k-file cap), `parse.rs` (series title via `library_link::extract_anime_title`, `release_title`'s `series_title`, with a parent-folder fallback that climbs past `Season 01`-style dirs; folder names skip it unless release tokens are present because it leaves out a bare trailing number (`100`); episode via `media::parse_episode_number`; season from `SxxExx`, else a trailing title marker `S3` / `Season 3` / `3rd Season` / `II`-`IV` that is stripped from the title (SubsPlease's `Title S3 - 18` otherwise sends AL a query it returns nothing for), else the series folder's marker when its title matches the file's, else a `Season N` folder), `matching.rs` (query building, ranking of AL `SEARCH_MATCH` results by title similarity + year + file-count-vs-format + season marker, low-confidence flag, and `fallback_queries`: the automatic pass retries an empty result with the bare title then the title cut at its subtitle; a typed re-search is searched as typed), `mapping.rs` (after the search, the group's TMDB-numbered season is resolved **by id** through `anibridge::tmdb_episode_spans`: files renumber into the AniList entry's own numbering (`source_episode` keeps the parsed one for the "was E05" note; `preview::import_file_name`, shared by the preview and the import, gives a file whose own name no longer reads as its episode the episode template's name, since every later disk check reads names), a TMDB season that AniList lists as two entries splits the group per entry, files no span covers stay with the search's pick; a mapped id the search didn't return is fetched by id via `entry_from_detail`; and `apply_absolute_numbering` for season-less folders whose numbers exceed the matched entry's count: walks the TV `SEQUEL` chain from the pick (`MAX_SEQUEL_HOPS = 8`, cached detail fetches; the forward twin of #30's PREQUEL-derived `cumulative_prior_episodes`) and routes files by cumulative range, renumbered per entry. Both automatic pass only, never on a user's pick / typed re-search), `preview.rs` (pure projection of per-file outcomes: Import / Replace via `source::is_valid_upgrade` / Already-have / Pinned / Downloading / No-episode / **Already-on-disk** (an untagged stranger at the destination path, checked only for folders that exist; never overwritten because `do_file_op` unlinks a pre-existing dst outside the recycle bin, and phase 1 re-checks it as a backstop) / Duplicate-name (per destination folder, so a special and an episode may share a file name); folder-collision suffixing), `session.rs` (the `AppState.import_sessions` store; eviction by TTL / cap never touches a `Scanning` or `Importing` session, since a running job only touches its session when it finishes). `mod.rs` runs the preview job under a `ProgressRegistry` handle keyed by the session id (walk → parse → group → match at `MATCH_CONCURRENCY = 4` → resolve existing series **by AL id, then MAL id for MAL-fallback rows only, never title**). Matched-existing tags snapshot into the session at resolve time so re-renders don't re-query. `import.rs` is the only mutating side: `start_import` (needs `Ready`, takes `IMPORT_LOCK` via `try_lock`, runs under progress id `<session>-import` so the scan job's still-buffered terminal event can't close the import toast) → per group **re-resolves the library row fresh** (the preview snapshot may be stale; this is what makes a re-run idempotent) → `series::upsert` from the search entry like `add_series` (created series get `monitor_mode = future` so an import never backfills) → `preview::unique_folder_name` against live disk state → `metadata_sync::refresh_series_metadata` (gated by `ImportOptions.hydrate_metadata`, off in tests) → per file: on Replace, `recycle::recycle` the old file(s) found via `media::scan_series_folder` (this season's file first: a merged folder's `Season 02/S02E05` is taken for episode 5 only when no season-1 or unnumbered file is, `EpisodeFile::is_own_season`, as in the delete handler) + `mark_grab_history_replaced` + `clear_episode_tag` (a refused recycle skips the file, never overwrites), then `post_processing::do_file_op(mode)` + episode NFO → `post_processing::scan_series_for_unclassified` for the classify/tag/history writes → `post_processing::write_series_sidecars` (artwork + tvshow/season NFO; helper shared with the post-processing tail). Cancel is an `AtomicBool` on the session checked between files.
